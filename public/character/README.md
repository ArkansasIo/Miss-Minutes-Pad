# Character Assets

Place original, licensed, or user-provided character artwork in this directory.

The repository intentionally does not include copyrighted Marvel/Disney promotional artwork or unauthorized voice recordings.

Recommended files:

- `idle-01.svg`
- `idle-02.svg`
- `listening.svg`
- `thinking.svg`
- `speaking-01.svg`
- `speaking-02.svg`
- `alert.svg`

The frontend can fall back to the built-in CSS/SVG clock avatar when these assets are absent.
